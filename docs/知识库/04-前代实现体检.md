## 5. 缺陷与债务

    P1-1 BT 选文件测试失败：仓库当前不可原样发布。
    P1-2 缺「下载完成 -> 统一后处理」管线（非 HLS 的 ts/mkv/flv/webm 不会自动转 MP4；无钩子抽象）。
    P1-3 多线程无动态性：静态均分被慢连接拖尾。
    P1-4 磁力失败模式不清晰：需要「为什么慢/怎么救」的可解释状态，而非静默低进度。
    P2-1 IDE 垃圾文件 core/internal/download/hlsx/# Tools Configuration.md（11.7KB，2026-11-06 GoLand 误写，未跟踪）。
    P2-2 仓库卫生：fastdl/ 躺在 gopeed 仓内未跟踪；根目录散落 _smoke13.txt/_thls.txt/_b13.txt 等。
    P2-3 httpx 单测 49s：全绿但偏慢（建议 short/long 分层）。
    P2-4 GUI 装机体验无人验证 [U]：「不顺手」需用户给具体点位。

## 6. 对 Sun_Tey 的处置建议

    内核按「可移植资产」对待：httpx / hlsx / bttx / store / server 是已验证代码，
    迁入 Sun_Tey 时保留其测试（测试是真正的价值来源），并在 P1-1~P1-4 上继续开发。
    UI 与扩展按新设计重做（这是用户不满的集中区）。
    禁止：把 gopeed/aria2 源码搬过来（GPL）；使用 IDM/迅雷 任何二进制或资源。
