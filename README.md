# Sun_Tey

装完就用的 Windows 下载器：**HTTP/HTTPS 多线程 + BT + 磁力 + 网页视频嗅探 + 下载后自动转 MP4**。
对标 IDM 的多线程与迅雷的磁力体验，目标只有一个——**不需要配置，装好就能下**。

> 状态：开发中（内核与打包路线来自已验证的前代实现，UI/扩展/后处理按新设计重做）。
> 施工计划见 [`docs/施工图-BLUEPRINT.md`](docs/施工图-BLUEPRINT.md)，工程约束见 [`docs/规则要求-RULES.md`](docs/规则要求-RULES.md)。

## 我要解决的问题

gopeed 很强，但作为一个「我每天要用的下载工具」它不合格：装完要配 API、装扩展要走 git、国内装扩展基本失败、界面不顺手。
Sun_Tey 反过来做：**零配置**（随机回环端口 + 扩展自动配对）、**扩展随安装包分发**（不碰 git）、**下完自动转 MP4**、**装完不用打开设置也能下载**。

## 能力一览

| 能力 | 说明 |
|---|---|
| 多线程下载 | IDM 式 Range 分片 + 慢启动扩连 + 慢连接动态再分配 |
| **断点续传** | 强杀进程、断电、重启系统、拔网恢复后精确续传：HTTP 按 Range、BT 按 piece 位图、HLS/DASH 按分片清单；源文件变更会明确提示而不是默默重下 |
| BT / 磁力 | 种子、磁力、tracker 订阅合并；磁力有「元数据加载中 / N 个对等点 / 暂无可用资源」三态提示；下载前勾选文件 |
| 网页视频 | Chrome / Edge 扩展嗅探页面媒体，悬浮按钮 + 媒体面板，带 Referer/Cookie 回源 |
| 自动转 MP4 | 下载完成后自动转封装或转码为 H.264/AAC MP4，支持字幕内封 |
| 去水印 | 固定矩形台标修复（仅处理自有素材，默认关闭） |
| 零配置 | 首次启动自动建目录、自动配对浏览器、失败给人话原因 |

## 诚实边界（请务必看）

- **「下载网页上任何视频」= 任何\*非 DRM\*视频。** 直链 mp4/webm/ts、无加密 HLS(m3u8)、无加密 fMP4/DASH 支持；
  MSE/`blob:` 流只能抓它背后的分片，不保证完整。
- **Widevine / FairPlay / PlayReady 等 DRM 一律不做。** 遇到加密流会明确提示，而不是给你一个假装在跑的进度条。
- **去水印**只针对你有权处理的素材上的固定台标/角标，不做平台水印去除，不做批量搬运。
- 磁力依赖公共网络：冷门资源可能真的很慢，这不是「加速会员」能变出来的，我们不假装能加速。

## 快速开始（开发中）

```powershell
# 内核
cd core && go build ./... && go test ./... -count=1

# UI 壳
cd app && npm install && npm run build

# 打包安装包
./packaging/build.ps1        # 产出 Sun_Tey-Setup-<版本>.exe
```

浏览器扩展在 `extension/`，开发期用「加载已解压的扩展程序」装载；正式安装包会附带一键安装引导。
